Import custom block

Add a namespaced block ID, display name, Bedrock geometry model and one or more textures. Files are saved to your private project library.

Upload multiple textures when the model has different material names. Each filename is matched to the model material; the first texture is the fallback for all faces.

Model size: 2 MB max. Texture size: 5 MB each, 12 MB total.
